CARTE INTERACTIVE DES ENTREPRISES

Le dossier contient :
- index.html : page de la carte
- style.css : mise en forme
- script.js : fonctionnement de la carte
- data/entreprises.geojson : données converties depuis le Shapefile

Pour tester :
1. Ouvrir index.html avec un navigateur.
2. Pour publier gratuitement : créer un dépôt GitHub, envoyer tous les fichiers,
   puis activer GitHub Pages dans Settings > Pages > Deploy from branch > main/root.

La carte contient 558 entreprises et permet de rechercher une entreprise,
cliquer sur un point et afficher ses informations.
